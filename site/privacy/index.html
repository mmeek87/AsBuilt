Privacy and support

AsBuilt is free, open-source software maintained by Mel Meek. There is no AsBuilt account or hosted service, and AsBuilt collects no personal information. Everything below describes software that runs in your own GitHub repository or on your own computer.

What the GitHub Action does

  • Runs on your repository's GitHub Actions runner when a preview deployment finishes.
  • Opens only your preview's address and reads the .asbuilt check files in your repository.
  • Posts or updates one comment on the pull request, using your workflow's own GITHUB_TOKEN.
  • Saves screenshots as a workflow artifact in your repository, kept for as long as your GitHub settings keep artifacts. Password fields are masked.
  • Sends secrets you add, such as a test account or a Vercel bypass secret, only to your preview's own address.

What the plugin does

The AsBuilt plugin for Claude and ChatGPT is a set of instructions plus a small helper that talks only to an AsBuilt service on your own computer (127.0.0.1). Your assistant processes your prompts and any results you share with it under that assistant's own privacy terms.

What AsBuilt never does

  • Send data to the maintainer or any third party
  • Add analytics, telemetry, cookies or tracking
  • Make purchases or payments, or submit real forms
  • Commit to your repository without your permission

This website is hosted on GitHub Pages, which may keep standard server logs under GitHub's privacy statement. The site sets no cookies and loads no third-party scripts.

Get help

Ask questions or report problems in GitHub Issues. Please leave out passwords, private code and personal data. To report a security issue privately, follow the security policy.

Remove AsBuilt

Uninstall the plugin in your assistant, then delete .github/workflows/asbuilt.yml and the .asbuilt folder from your repository. Screenshots already saved as workflow artifacts expire on GitHub's schedule, or you can delete them from the workflow run.
