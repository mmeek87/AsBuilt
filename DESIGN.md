# AsBuilt design system

## Direction

A compact application workspace inspired by the user's references: Notion, Buy Me a Coffee, stoic, and Midday. The prior editorial/serif treatment was rejected. Do not bring back a marketing hero, paper palette, promotional sidebar, or large display serif. Design starts with the user's task and actual data.

## Composition

A 228px quiet navigation rail, 67px breadcrumb bar, and a focused 760px working canvas. Three destinations only: New review, Past reviews, Connections. Navigation becomes a compact top row on phones. The review editor groups intent and target context together; history and connection setup have dedicated views. No fabricated metrics, unsupported controls or ornamental dashboard cards.

## Identity and tokens

Public Sans throughout. Wordmark uses a compact paired-bracket symbol in charcoal with muted yellow. White canvas #ffffff; neutral rail #f7f7f4; ink #252522; muted #696962; rules #e5e5df. Yellow #f8df83 appears in the active workflow step and brand mark. Black primary actions. Focus charcoal #363630; a continuous 2px indicator surrounds the complete editor, with no offset gap. Other keyboard focus outlines are 2px with a 2px offset. Form boundary #92928a for non-text contrast. Standard form radii 7–10px; no gradients or decorative shadows. 30px main headings, 13–14px working text, 16px phone inputs.

## Interaction and accessibility

Visible input labels, native radio/checkbox semantics, aria-current navigation and progress, focus-visible outlines, skip link and correct headings. Editing a draft survives navigation. Real loading, error and empty states. Pass / Fail / Not verified text never relies only on color. Preview approval and source-sharing consent remain explicit. Sidebar privacy copy distinguishes local reports from approved source sharing.

## Reference use

Notion: familiar separation of navigation and editor. Midday: restrained application chrome and concrete workspace content. Buy Me a Coffee: approachable controls and a small, confident accent. Stoic: a single focused prompt with calm spacing. These are interpretive design influences, not copied layouts or assets.

## Validation

Desktop and 390px mobile screenshots, complete sample flow, keyboard navigation, overflow and automated axe checks. Separate history/setup navigation coverage. This is not a full WCAG or screen-reader certification. User acceptance of this revision remains open.
